# Mac 뽀모도로 앱 설계

## 목적과 합의된 범위

Mac에서 작업별로 집중 시간을 관리하고, 각 집중 세션이 끝나면 무엇을 했는지 기록하며, 일·주·월 단위로 돌아볼 수 있는 개인용 앱을 만든다. 사용자가 제공한 세 장의 이미지를 메인 요약 화면, 플로팅 타이머, 회고 대시보드의 시각적 기준으로 삼는다.

필수 기능은 집중·휴식 시간 설정, 줄어드는 부채꼴 플로팅 타이머, 집중·휴식 종료 시 짧은 종소리, 집중 종료 시 메모 창 자동 표시, 회고 대시보드다. 로그인과 클라우드 동기화, 유료 기능은 초기 범위에 포함하지 않는다.

## 구현 방식

SwiftUI로 화면을 구성하고 AppKit의 NSPanel로 플로팅 창과 메모 창을 관리한다. macOS 14 이상을 대상으로 한다. Swift Package로 앱과 테스트를 구성하고, 스크립트로 실행 가능한 .app 번들을 만든다. 외부 패키지 없이 시스템 프레임워크를 사용한다.

SwiftUI와 AppKit 조합은 Mac 전용 창 동작에 적합하다. Electron은 웹 UI 개발이 쉽지만 실행 환경을 함께 배포해야 하며, 이 앱에서는 네이티브 구현을 선택한다.

## 화면과 시각적 구성

전체 화면은 연한 연보라 배경, 둥근 흰 카드, 회색 텍스트, 빨간 강조색을 사용한다. 앱 UI 언어는 한국어다. 창 크기가 작아지면 카드 배치를 조정하고 본문을 스크롤할 수 있게 한다.

### 메인 화면

- 왼쪽 사이드바: 작업 목록, 작업 추가, 설정 진입.
- 상단: 선택한 작업의 이름과 색상, 이름 수정과 삭제.
- 본문: 요약 / 회고 탭.
- 하단: 현재 집중 또는 휴식 단계, 남은 시간, 시작·일시정지·종료, 플로팅 창 열기.
- 최초 실행 시 기본 작업 하나를 제공한다. 실제 기록이 없으면 통계는 0과 안내 문구로 표시한다.

### 요약 탭

오늘·이번 주·이번 달의 집중 시간, 횟수, 평균 집중 시간, 직전 동일 기간 대비 증감과 전체 누적을 표시한다. 선택한 작업의 활동 히트맵, 최근 일별 집중 시간 막대그래프, 작업별 시간 비중 도넛, 최근 메모를 제공한다. 도넛은 전체 작업 기준임을 명시한다. 휴식 시간은 집중 통계에서 제외한다.

### 회고 탭

사용자의 회고 이미지에 따라 일간·주간·월간 선택과 기간 이동을 제공한다. 일간은 선택한 날짜, 주간은 월요일부터 일요일, 월간은 달력상의 한 달을 뜻한다. 해당 기간의 총 집중 횟수와 시간을 상단에 표시한다.

기록은 날짜별 카드로 묶고 최신 날짜와 세션부터 나열한다. 날짜 카드는 날짜·횟수·총 시간을 표시하며 접기·펼치기를 지원한다. 펼친 내용은 세로 타임라인에 시작 시각, 실제 집중 시간(분), 메모를 표시한다. 메모가 없으면 ‘메모 없음’을 표시하고, 기록을 클릭하면 수정할 수 있다. 날짜 경계를 넘긴 세션은 시작한 날짜에 귀속한다.

### 플로팅 타이머

다른 일반 창 위에 유지되는 이동 가능한 작은 창으로 제공한다. macOS가 허용하는 범위에서 다른 Space와 전체 화면에서도 표시한다. 창 닫기는 표시만 해제하고 타이머는 유지한다.

사용자의 원형 타이머 이미지를 따라 12시를 0으로, 시계 방향으로 5·10·15…55 눈금을 배치한다. 60분 이하 설정에서는 남은 25분이 150도 부채꼴을 차지하며, 남은 시간이 줄면 부채꼴도 줄어든다. 시간 설정 범위를 집중 1~60분, 휴식 1~60분으로 두어 눈금과 시간을 일치시킨다. 집중은 빨강, 휴식은 차분한 초록으로 구분한다. 단계명, 남은 시간, 시작·일시정지와 메인 창 열기 버튼을 제공한다.

### 설정

집중 시간 기본 25분, 휴식 시간 기본 5분. 각각 1~60분으로 설정한다. 종료 종소리 켜기·끄기와 미리 듣기, 다음 단계 자동 시작(기본 꺼짐)을 제공한다. 실행 중 변경한 시간은 다음 세션부터 적용하며 이를 설정 화면에서 안내한다.

## 타이머와 메모 동작

집중 준비 → 집중 실행 ↔ 일시정지 → 집중 완료 → 휴식 준비/실행 → 휴식 완료 → 집중 준비/실행 순서다. 수동 시작이 기본이고 자동 시작을 설정하면 완료 직후 다음 단계를 시작한다.

집중 완료 시 다음 작업을 한 번만 수행한다.

1. 작업 ID, 시작·종료 시각, 실제 집중 시간, 완료 여부, 빈 메모를 가진 기록을 저장한다.
2. 소리가 켜져 있으면 짧은 종소리를 재생한다.
3. ‘이번 집중 시간에 무엇을 했나요?’ 메모 창을 표시한다.
4. 자동 시작 설정에 따라 휴식을 준비하거나 시작한다.

메모 창은 작업명과 집중 시간을 함께 보여주며 저장 / 건너뛰기를 제공한다. 닫기와 건너뛰기는 집중 기록을 유지한다. 자동 휴식은 메모 입력 중에도 흐른다. 메모는 세션 ID에 연결하며 이전 메모 창이 열린 상태에서 다른 집중이 완료되면 미작성 세션을 순서대로 제공한다. 휴식 완료 시 종소리만 재생하고 메모는 요청하지 않는다.

집중을 도중에 종료하면 실제로 집중한 시간이 1초 이상일 경우 부분 세션으로 저장하고 메모 창을 연다. 1분 미만은 ‘1분 미만’으로 표시한다. 부분 세션도 집중 시간과 횟수에 포함하고 중단 표시로 구별한다. 일시정지 시간은 집중 시간에서 제외한다. 실행 중에는 작업 변경을 막고 먼저 종료하도록 안내해 기록 귀속을 명확히 한다.

## 시간 정확성과 재실행

매 틱마다 시간을 차감하는 방식 대신 종료 예정 시각과 현재 시각의 차이로 남은 시간을 계산한다. UI 갱신은 주기적으로 수행하되 완료 처리는 세션 ID 기준으로 중복을 차단한다.

잠자기 동안에도 실행 중인 타이머의 시간은 경과한다. 복귀 시 이미 끝났다면 원래 종료 예정 시각으로 해당 세션 한 건을 완료한다. 자리를 비운 동안 여러 집중·휴식 기록을 연쇄 생성하지 않는다. 자동 시작을 켰어도 다음 단계는 복귀한 현재 시점부터 시작한다.

현재 세션과 일시정지 상태를 저장하고 재실행 시 복원한다. 실행 중이던 세션이 종료 시각을 지났다면 한 번만 완료 처리하고 메모를 제공한다. 앱이 종료된 동안에는 소리를 낼 수 없으며 재실행 시 완료를 알린다.

## 데이터와 구성 요소

- TimerEngine: UI와 독립적인 상태 전이, 종료 시각 계산, 일시정지, 완료 이벤트.
- AppStore: 작업·설정·기록·현재 세션을 관리하고 완료 이벤트를 저장 및 창 표시로 연결.
- LocalRepository: Application Support의 앱 전용 폴더에 버전이 있는 JSON을 원자적으로 저장.
- Statistics: 기간 필터, 날짜별 집계, 평균·비교·차트 데이터 계산.
- WindowCoordinator: 메인 창, 플로팅 패널, 메모 창 표시와 생명주기 관리.
- BellPlayer: 앱에 포함된 짧은 종소리 파일을 시스템 오디오 API로 재생.

작업 삭제에는 관련 기록 수도 함께 표시해 확인을 받는다. 마지막 작업은 삭제할 수 없으며 이름을 바꿀 수 있다. 메모 수정은 저장 시 즉시 통계와 회고에 반영한다. 기록 로드 실패 시 원본 파일을 덮어쓰지 않고 오류와 복구 경로를 안내한다. 저장 실패는 사용자에게 알리고 메모 입력을 보존해 재시도할 수 있게 한다.

## 검증과 전달

타이머 상태 전이, 일시정지 제외, 완료 중복 방지, 시간 경과 후 복원, 부분 종료 기록, 날짜 경계와 기간별 집계, 저장·복원을 단위 테스트한다. 짧은 검증용 세션으로 집중 완료 → 메모 → 휴식 완료의 실제 흐름과 소리 재생을 확인한다.

앱 빌드 후 메인 화면·회고·플로팅·메모·설정 창을 실제로 열어 배치와 동작을 확인한다. 사용자에게 .app 위치, 실행 방법, 검증 결과와 남은 제한을 전달한다. 초기 전달은 로컬 실행용이며 App Store 배포와 공증은 범위 밖이다.
