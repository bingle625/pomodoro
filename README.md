# Pomodoro for Mac

집중과 휴식 시간을 관리하고, 집중이 끝날 때 메모를 남기는 한국어 Mac 앱입니다. 메인 화면에서 요약 통계와 날짜별 회고를 보고, 다른 창 위에 작은 원형 타이머를 띄울 수 있습니다.

## 실행

빌드된 앱은 `dist/Pomodoro.app`입니다. Finder에서 더블 클릭해 실행할 수 있습니다. 최초 상태는 집중25분·짧은 휴식5분·긴 휴식15분(집중4회 완료마다), 자동 시작 꺼짐이며 기록은 비어 있습니다.

- 작업을 추가하거나 선택하고 하단 ▶ 버튼으로 시작합니다.
- 하단 플로팅 버튼 또는 `⌘2`로 항상 위에 표시되는 타이머를 엽니다. 다이얼이나 상단 제목을 드래그하면 창이 이동합니다. 닫아도 타이머는 계속됩니다.
- 집중 종료 시 짧은 종소리와 메모 창이 표시됩니다. `⌘Return`으로 저장하고 Return으로 줄바꿈합니다.
- 회고 탭에서 일·주·월별 기록을 조회하고 기록을 눌러 메모를 수정합니다. 집중 히트맵은 최근 월이 왼쪽에 오며 오른쪽에서 왼쪽으로 쌓입니다.
- `⌘,`에서 집중/짧은 휴식/긴 휴식 시간을 각각1~60분으로, 긴 휴식 주기를 집중1~12회로 설정하고 종소리·자동 시작을 선택합니다.
- 메인 화면은 `⌘1`로 다시 열 수 있습니다. 메인 창을 닫아도 앱은 종료되지 않습니다. 완전히 종료하려면 `⌘Q`를 사용합니다.

긴 휴식 주기는 완료한 집중만 세며, 긴 휴식으로 전환하면 다시 시작합니다. 완료 횟수는 앱을 재실행해도 유지됩니다.

중도 종료한 집중은1초 이상이면 부분 기록으로 저장되며 ‘중단’으로 표시합니다. 일시정지는 집중 시간에서 제외됩니다. 잠자기 동안에는 시간이 경과하며, 늦게 돌아와도 끝난 세션 한 건만 기록합니다. 자동 시작된 다음 단계는 복귀 시점부터 시작합니다.

## 빌드와 테스트

macOS14 이상과 Swift5.9 이상을 지원하는 Xcode/Command Line Tools가 필요합니다. 실제 빌드는 Apple Silicon의 Swift6.4 환경에서 검증했습니다. SwiftPM이 고정 버전의 Sparkle2.10.0을 자동으로 다운로드합니다.

```sh
swift test
bash scripts/build-app.sh
```

스크립트는 release 실행 파일과 종소리 리소스를 `.app`에 넣고 로컬 임시 서명(ad-hoc)을 적용합니다. App Store 배포나 Developer ID 공증은 포함하지 않습니다. Intel 및 macOS14 실기기 실행은 별도 검증이 필요합니다.

## 자동 업데이트

v1.1.0부터 새 릴리스를 자동 확인·다운로드합니다. 타이머와 메모가 끝나고 편집 창을 닫으면 설치·재실행합니다. 설정에서 자동 확인과 자동 설치를 끌 수 있고 ‘지금 확인’으로 수동 확인할 수 있습니다. **v1.0.0 사용자는 v1.1.0을 한 번 직접 설치해야 합니다.**

[자동 업데이트 및 다음 릴리스 배포 방법](docs/automatic-updates.md)을 참고하세요.

## 저장과 복구

설정·작업·기록·진행 중 세션은 다음 파일에 함께 저장됩니다.

```text
~/Library/Application Support/Pomodoro/state.json
```

저장은 원자적으로 처리합니다. 읽기 오류나 지원하지 않는 버전은 기존 파일을 덮어쓰지 않고 화면에 경로와 오류를 표시합니다. 저장 실패 시 ‘다시 시도’를 사용하세요. 저장하지 못한 변경이 있으면 종료 전에 재시도를 안내합니다. 진행 중인 세션은 재실행 때 복원됩니다. 앱이 종료된 동안에는 소리가 울리지 않고 재실행 시 완료를 처리합니다.

개발 검증에서는 환경변수 `POMODORO_DATA_PATH`에 **별도의 테스트 파일 경로**를 지정할 수 있습니다. 기본 사용자 기록과 섞이지 않도록 사용하세요. 배포 앱은 이 변수가 없으면 위 기본 경로를 사용합니다.
